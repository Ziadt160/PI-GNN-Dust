# Results

Every file here is cited by the README or the [research log](../docs/research_log.md),
or is an input to a script that reproduces a cited number. Run outputs that are
not (smoke tests, ablation arms, per-epoch logs, resumable checkpoints) are
git-ignored.

## Phase 3 — observed dust events (`experiments/station_dust/`)

| File | What it is |
|---|---|
| `baselines_station.json` | The controls in the README's results table: never-dust, climatology, wind threshold, persistence, logistic regression, gradient boosting. 24 h, daily, `dust_storm`. |
| `station_daily_interior.json` | The flux-GNN scored at 3 / 24 / 48 h on all three grades, with (`obs`) and without (`no-obs`) the station's current reading as input. The headline TS 0.142 is `24h\|dust_storm\|no-obs`. |
| `station_daily_interior_era5.json` | The same run with measured ERA5 emission drivers instead of the proxy: research log finding 8 (no change beyond noise). |
| `feature_importance.json` | Permutation importance by input channel (finding 5). |
| `operating_points.json` | POD / FAR across decision thresholds per horizon (finding 6). |
| `interior_mask.npy` | Cells whose 8 neighbours are all valid land: the supervised and scored set. |
| `station_model_{3h,24h,48h}.pt` | `DustTransportGNN` weights (hidden 64, 32 input channels), one per horizon. The run that produced them is not recorded with them, and they are not the model behind `station_daily_interior.json`. |

## Phase 2 — CAMS PM10 on the Saudi domain (`experiments/saudi_pm10/`)

| File | What it is |
|---|---|
| `aidust_screening.json`, `aidust_final.json`, `aidust_rollout.json`, `aidust_benchmark.json` | The AI-DUST comparison, scored **against CAMS**: screening, final runs, autoregressive rollout, and the benchmark summary. |
| `preds/*.npz` | Raw test-period predictions of the eight final models. Read by `validate_vs_metar.py` and `rescore.py`. |
| `metar_validation.json` | Those predictions scored **against airport observations**, where the ranking inverts (finding 2). |
| `rescored.json` | The same predictions rescored with SEDI and base rates, from `rescore.py`. |
